# generation

Adds one hazard to a car photo with [FLUX.1 Kontext [dev]](https://bfl.ai/blog/flux-1-kontext-dev).

| | |
| --- | --- |
| **Input** | A CompCars photo and a hazard prompt (target class and instruction) |
| **Output** | The edited image and its metadata: source photo, prompt, seed, model version |
| **Owner** | To be assigned |
| **Check** | Tests linked to R1. KPI: at least 50% of each class's images pass validation |
