# export

Checks that the annotations are consistent and writes the final dataset.

| | |
| --- | --- |
| **Input** | Accepted images, their masks and metadata |
| **Output** | The annotated synthetic dataset: image, hazard class, segmentation mask and metadata |
| **Owner** | To be assigned |
| **Check** | Tests linked to R3: the dataset passes integrity checks and loads in the target training pipeline |
