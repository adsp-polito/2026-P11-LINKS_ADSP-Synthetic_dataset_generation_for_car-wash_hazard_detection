# data

Inputs for the pipeline.

**No images are stored in this repository.** CompCars is licensed for non-commercial research only and does not allow redistribution, and the full dataset is about 20 GB.

| Folder | Content | In git? |
| --- | --- | --- |
| `raw/` | CompCars photos, downloaded locally | No |
| `prompts/` | One entry per hazard class: target class and editing instruction | Yes |
| `manifests/` | Lists of the source photos selected for each class and viewpoint | Yes |

Download steps will be added with the first code.
